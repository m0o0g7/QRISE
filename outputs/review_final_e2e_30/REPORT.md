# 실제 컴포넌트 실행 결과

프로필: `mechanism_e2e`. Baseline 정제: 경로 최저 예상 F의 MPR, 추가 라운드 없음.
스케줄: `v1_incremental_swap`. 저장 결과 30 / 30회.
각 링크 준비 후 즉시 BSM·보정을 완료하고 다음 링크를 진행한다. 모든 정책에 같은 실행기를 사용한다.
첫 링크와 누적 얽힘 쌍은 후속 링크를 기다리며 메모리 잡음을 받는다.

F는 목표 미달 완성 쌍을 포함하고, 생성 시도·지연은 실패 요청도 포함한다.
비용과 목표 충족률을 함께 비교한다. 경로 adapter는 원 논문의 전체 프로토콜 구현이 아니다.
원문은 점진적 MCSFM을 설명하지만 gate scheduling과 재시작 절차까지 공개하지는 않았다.
적은 seed의 실행은 동작 점검용이며 Fig.2 경향 재현의 통계적 검증은 별도다.

## 공개되지 않은 입력 가정

- 공통 초기 F: 거리/위상 곡선 + 0.005 + 선언된 링크별 품질 오프셋.
- 공통 실제 메모리 depolarization rate: 0.01 /s/큐비트.
- Eq.(3) alpha=10.0; baseline 후보의 fidelity 필터=False. 경로 점수 규칙 자체는 유지한다.
- Q-RISE guard=chain, 예측 구간=20.0 slots. Baseline 공통 링크 floor 적용=False.
- 링크 floor=0.0 + 0.0 × target; 준비 후 실측 F를 보장하는 사후 판정이 아니라 계획 기준이다.
- 열화 링크 비율=0.2, 품질 진폭=0.012, 품질 주기=120.0 slots; 합성 입력이며 실제 LEO 궤도 자료가 아니다.
- 링크 관측은 기존 1슬롯 Gao aging을 유지한다. chain 모드의 누적 예측은 실제 processor 잡음률로 대기 노화를 반영한다.
- 현재 예측의 전방 도달 가능성 검사=True. 전체 링크 상태가 알려졌다는 추가 계획 가정이다.
- 전체 요청 cutoff 224 slots; 포스터의 링크별 cutoff와 구분해야 한다.
- 입력 선택에 활용한 seed1701–1703의 결과는 독립 검증으로 간주하지 않는다.
- 정제 성공 확인·유한 메모리·홉별 BSM 이벤트는 공통 실행기를 사용한다.

절감률은 실패 비용을 포함한 요청당 평균의 비율이다. 성공률이 다르면 같은 서비스 품질의 절감으로 해석할 수 없다.
숫자·노드별 실패를 강제로 맞추지 않는다. 성공한 baseline, 목표 미달 및 cutoff도 모두 표에 포함한다.
